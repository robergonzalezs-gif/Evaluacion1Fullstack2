EJECUTAR EL SISTEMA COMPLETO
Proyecto contiene frontend, backend, SQL, Docker, Compose y el JAR con React integrado.
Abra PowerShell en Proyecto y ejecute:
powershell -ExecutionPolicy Bypass -File .\Iniciar-Entrega.ps1
Requiere Docker Desktop activo, contenedores Linux e Internet para las imágenes.
Lea Proyecto/README.txt para alternativas y configuración.
